# Axis dashboard generator

0. `python build_posts.py` rebuilds the raw post table for the threat-targets section (`AXIS_POSTS`, default `/workspace/threats/posts.pkl`) from the new collection export: every `<crawl dir>/posts/<handle>.csv` (Telethon/Eitaa export, columns `post_id,date,url,text,views,...`) under the IRGC bot working folder, with group taken from `v3/merged/nodes.csv`. Options: `--work W`, `--since 2026-05-01`, `--out PATH`, or pass specific crawl dirs. Output columns date,url,text,views,channel,group, deduplicated on url, written atomically. Run it after the weekly collection lands and before step 1. **`--merge EXISTING_PKL` keeps the history**: the old table is loaded first, the new CSV rows are added and the result is deduplicated on url (without it only the CSVs you pass survive). The work folder is `--work` or the `AXIS_WORK` env var.
1. `python build_data.py` recomputes every number from the latest collection (30-day window ending at the newest post; 7-day "new this week" vs the 3 weeks before) and writes `../data.json`. It reads aggregate CSVs from the work folder `W` (argv[1] or `AXIS_WORK`, default `/workspace/axis_inputs/W`), the codebook table `AXIS_TABS` (default `/workspace/axis_inputs/codebook/tabs.pkl`) and writes `AXIS_OUT` (default `../data.json`). It holds no keys or session data.
2. `python gen_page.py` turns `data.json` into `../index.html` (static, one GA tag G-Z61EKRP8QV, Cartel dark theme). No numbers are hard-coded in the page template.
3. The Houthi threat-targets section (incl. named-site map bubbles `sites`, per-bubble site/type breakdown `kind`, and the threats-only "New this week" block `week`) is computed by `threats.py` (called from `build_data.py`) from the raw post collection (path in `AXIS_POSTS`, default `/workspace/threats/posts.pkl`; columns date,url,text,channel,group) plus the coordination copies table. If the posts file is missing, the previous result in `data.json` is kept.
4. The Hamas threats part (after the Houthi trend chart) comes from `hamas_threats.json`, a small curated file copied into `data.json` as `hamas_threats` by `build_data.py`: target counts, Abu Obeida calls, Axis pickup counts and the dated statements list. It is built by hand from the Threats and Threat counts tabs of the Hamas sheet (Google Sheet 1yTCPulpFXWgnGAGcm07MylUpwO3hg5wRBNiRUy23cg4) and is not recomputed by the weekly build. The wording is taken from reposts, because the six official Hamas channels cannot be read from a US client. `test_figures.py` checks that the page figures match this file.
5. `week_tr.json` holds English translations for the "New this week" Arabic excerpts, keyed by item id. After each rebuild, items without an `en` text show "translation pending": add their ids here and rebuild.

## Weekly rebuild

`rebuild/rebuild_axis.sh <new crawl dir> [...]` runs the whole sequence in a scratch copy and diffs the result against the live `data.json` (it never changes the live page):

1. `rebuild/setup_env.sh` creates the venv (`AXIS_VENV`, default `/workspace/axis_venv`; pandas 3.1.0, see `rebuild/requirements.txt`; the box's system pandas is broken).
2. `build_posts.py --merge $AXIS_POSTS_MASTER` merges the new CSVs into a copy of the master `posts.pkl`.
3. `rebuild/regen_inputs.py` regenerates `W/v3/merged/{nodes.csv,coordination_copies_v4.csv,coord_stats.json}` from the merged posts (`rebuild/coord_lib.py` holds the clustering: normalised text of 60+ characters posted by two or more channels).
4. `rebuild/payment_rails_src/{ex.py,build.py}` rebuild `W/payment_rails/{nodes,edges}.csv` by rescanning the raw crawl CSVs (`PAY_POSTS_DIRS` must list every crawl dir).
5. `build_data.py`, `gen_page.py`, `test_figures.py`, then `rebuild/compare_data.py` prints which sections changed against the live page.

Inputs that stay outside the repo (backed up on Drive, folder 1LJL6gW0wuXwtnGl8fLjealReC9HwMvVf, `axis_rebuild_inputs_2026-10-27.zip`): `W/v3/infra.json`, `codebook/tabs.pkl`, the raw crawl CSVs and the master `posts.pkl`. Approximations: the coordination table is re-implemented from the post table, so a few cross-group counts differ slightly from the Oct 26 page.
